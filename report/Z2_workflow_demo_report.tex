\sect{A bounded proposal-and-check cycle}
This demonstration connects a specified M-theory target to an LLM-proposed lattice representative and deterministic checks. It exercises the early stages of a dual-building workflow: geometric input, local action, lattice membership, order and a written level-matching condition.

\note{\textbf{Executed result.} Two reference samples pass the implemented checks; four deliberately invalid samples fail. The proposed representative remains \status{UNRESOLVED} as a complete heterotic dual. The full Narain embedding and spectrum are outside this calculation.}

\sect{Fix the geometric input}
Write the singular space as
\[
X_0=\bigl(T^3\times(T^4/G)\bigr)/K,\qquad G=K=\Z_2,
\]
with \(g(z^1,z^2)=(-z^1,-z^2)\) on the square four-torus. Its sixteen singular points are labelled by
\[
z^1=(a+ib)/2,\quad z^2=(c+id)/2,\quad(a,b,c,d)\in\mathbb F_2^4.
\]
The three actions considered for \(K=\Z_2\) give the following independently enumerated orbits:
\begin{center}\small
\begin{tabularx}{\linewidth}{@{}Yrr@{}}\toprule
\textbf{Action on \((z^1,z^2)\)}&\textbf{Fixed}&\textbf{Pairs}\\\midrule
\((-z^1,z^2)\)&16&0\\
\((-z^1,z^2+i/2)\)&0&8\\
\((-z^2,-z^1)\)&4&6\\\bottomrule
\end{tabularx}
\end{center}
The selected target is the \textbf{first row}: sixteen components of type \((A_1,T^3/\Z_2)\). The external action is fixed as
\[
(y^1,y^2,y^3)\longmapsto(y^1+\tfrac12,-y^2,-y^3).
\]
Choose one Higgs-type component and fifteen Coulomb-type components. The all-Coulomb assignment is a simple control within this same geometry. The other two rows only test geometric input handling.

\subsect{The demonstrated workflow}
\begin{enumerate}
\item Freeze the geometry, local target and arithmetic conventions.
\item Ask a model for one representative, with its reasoning archived.
\item Evaluate the proposal and seeded counterexamples with exact code.
\item Review the evidence and retain unresolved physical checks explicitly.
\end{enumerate}

\sect{The local branch target}
For one Higgs-type \(A_1\), the local target uses the Weyl representative
\[
w=\begin{pmatrix}0&1\\-1&0\end{pmatrix},\qquad w^2=-I.
\]
Conjugation on a basis of \(\mathfrak{sl}_2(\mathbb C)\) has eigenvalues \((+1,-1,-1)\). The code verifies these eigenvalues and all nine basis-bracket preservation identities. Thus this matrix has order four, while its adjoint action has order two.

The scalar directions have geometric parities \((+1,-1,-1)\). In a conjugate Cartan/root basis the invariant Cartan generator contributes scalar parities \((+1,-1,-1)\); each of the two odd charged generators contributes \((-1,+1,+1)\). One Higgs-type component therefore has complex dimensions \((1,2,2)\) in the three local chiral scalar sectors.

\begin{center}\small
\begin{tabularx}{\linewidth}{@{}Ycc@{}}\toprule
&\textbf{16 Coulomb}&\textbf{15 Coulomb + 1 Higgs}\\\midrule
Local algebra at origin&\(\su(2)^{16}\)&\(\su(2)^{15}\oplus\uu(1)\)\\
Gauge generators&48&46\\
Complex scalar dimensions&\((48,0,0)\)&\((46,2,2)\)\\\bottomrule
\end{tabularx}
\end{center}
The intended interpretation of the Higgs component is an \(\N=2\), \(SO(2)\) gauge theory with a hypermultiplet in its two-dimensional vector representation. Its generic Higgs branch leaves two complex moduli. This is the \emph{local target}; the demo does not derive the complete heterotic matter spectrum.

\sect{An abstract lattice representative}
Use orthogonal roots
\[
\alpha_{j,\pm}=e_{2j-1}\pm e_{2j},\quad j=1,\ldots,4,
\qquad V=\tfrac14(e_7+e_8).
\]
Pair root characters with \(V\) using the positive Euclidean coordinates. Then \(\exp(2\pi i\,\alpha\cdot V)=-1\) for \(\alpha=\pm(e_7+e_8)\), and it is \(+1\) on the other seven root pairs. Cartan generators remain even. A second abstract \(A_1^8\) is untouched.

Here
\[
E_8=\{x\in\Z^8\ \text{or}\ (\Z+\tfrac12)^8:\ \sum_i x_i\in2\Z\}.
\]
Consequently \(4V=(0^6,1,1)\in E_8\), while \(2V=(0^6,\tfrac12,\tfrac12)\notin E_8\). The order modulo this lattice is four, despite the order-two action on the chosen root subsystem.

\note{The ambient root set matters. On all 240 roots of an unbroken \(E_8\), this \(V\) retains 126 roots; on the chosen \(A_1^8\), it retains 14 roots. The subsystem calculation alone does not construct the required enhanced Narain background.}

\sect{Freeze the arithmetic conventions}
For this conditional example, take a gauge norm \(q_V=-\sum_i V_i^2\) and two hyperbolic planes \(U\oplus U\), each with Gram matrix
\[
U=\begin{pmatrix}0&1\\1&0\end{pmatrix},\qquad
q(x,y;u,v)=2xy+2uv.
\]
The negative gauge norm belongs to the written arithmetic convention. Root characters on page 2 were defined with the positive Euclidean pairing. These conventions are fixed inputs; they are not silently interchanged.

Set \(\phi=(\tfrac12,\tfrac12,0)\), so \(\phi^2=\tfrac12\). The scalar directions on page 2 list the invariant direction first; this is a relabelling of the twist planes. Test the written congruence
\[
N^2\bigl(q_V+q_\delta-\phi^2\bigr)\in2N\Z.
\]
This is a check of the stated level-matching formula, not a certificate of modular invariance of a complete asymmetric orbifold.

\sect{One Higgs-type component: \(N=4\)}
Restrict the torus shift to
\[
\delta=\left(\frac a4,\frac b4;0,\frac12\right),
\qquad a,b\in\{0,1,2,3\}.
\]
The external half-shift is null and has order two in the declared \(U\) basis. The three contributions are
\[
N^2q_V=-2,\qquad N^2q_\delta=2ab,\qquad N^2\phi^2=8.
\]
Thus
\[
-2+2ab-8\equiv0\pmod8
\quad\Longleftrightarrow\quad ab\equiv1\pmod4.
\]
All sixteen pairs are checked. Exactly \((a,b)=(1,1)\) and \((3,3)\) satisfy this congruence. The model proposed
\[
\boxed{V=(0^6,\tfrac14,\tfrac14),\qquad
\delta=(\tfrac14,\tfrac14;0,\tfrac12),\qquad N=4.}
\]
For this representative \(q_\delta=1/8\), \(4\delta=(1,1,0,2)\) is integral, and the congruence value is \(-8\), with residue zero modulo eight.

\subsect{All-Coulomb control}
Take \(V=0\), \(N=2\), and \(\delta=(a/2,b/2;0,1/2)\). The condition becomes \(2ab-2\equiv0\pmod4\). Of four pairs, only \((1,1)\) passes. This gives \(\delta=(1/2,1/2;0,1/2)\).

\note{The counts are raw representatives in the fixed ansatz. They are not counts of inequivalent backgrounds. Compatibility with the actual invariant lattice, gluing and operator action remains to be established.}

\sect{What the statuses mean}
\begin{itemize}
\item \status{PASS}: the supplied data satisfy the named implemented check.
\item \status{FAIL}: the data contradict that check or their declared target. This rejects this submitted construction under these conventions; it is not a general obstruction to a dual.
\item \status{UNRESOLVED}: the required physical data or calculation is absent. This is never promoted to a pass.
\end{itemize}
Malformed data are recorded separately as an execution \texttt{ERROR}, with no scientific pass/fail verdict. The two reference samples have overall status \status{UNRESOLVED}; the four invalid samples have overall status \status{FAIL}.

\note{\textbf{Validation:} 16 automated tests pass. They include reference orbit counts, an explicit-multiple oracle for lattice order, a separately derived \(ab\equiv1\pmod4\) reference, input mutations and malformed-input handling. The suite reports zero execution errors for the six intended samples.}

\sect{An actual model proposal}
A fresh agent received the geometric input, the orthogonal root frame, the requested local phases and the conditional torus ansatz. Its prompt did not contain the expected \(V\), the value of \(N\), the successful \(\delta\), or the reference scan output. It was instructed not to inspect prior artifacts or other agents.

The returned numerical proposal is the boxed representative on page 3. Evaluating its actual fields gives \status{PASS} for the nine implemented checks and \status{UNRESOLVED} for the complete construction. No numerical field was changed.

The archived reasoning needed one clarification. It described scalar signs \((-1,+1,+1)\) as applying ``on one \(A_1\).'' These signs apply to the two charged generators. The Cartan generator has scalar signs \((+1,-1,-1)\), so the full invariant dimensions are \((1,2,2)\). The report and checker state this explicitly.

\note{This clarification was made during assistant review. It is not presented as an independently completed human check. The four adversarial fixtures are separate seeded errors, not mistakes attributed to the proposing model.}

\sect{Reproduce the computation}
From the repository root (or an extracted archive):
\begin{quote}\ttfamily\small
python3 checker.py\par
python3 -m unittest -v\par
python3 verify\_proposal.py
\end{quote}
The checker uses Python's standard library and exact \texttt{Fraction} arithmetic. It refuses floating-point candidate inputs. The notebook \texttt{demo.ipynb} explains the same calculation; Jupyter is optional for the command-line run.

The machine-readable output is deterministic. Reproduction of the numerical evidence does not require a model call or regeneration of the model's prose. The README includes a reporting format for an external reproduction; none is claimed in this release.

\sect{The physical review boundary}
The demo establishes geometric orbit counts, an abstract local field projection, lattice membership and arithmetic order in the stated factors, and one written level-matching congruence. It does not establish a complete dual pair.

For a complete construction, the actual massless Narain vectors \(P\) must be specified. They may have toroidal momentum, winding or Wilson-line components. Their full characters involve
\[
\exp\bigl(2\pi i\,P\cdot(V+\delta)\bigr),
\]
with the pairing evaluated in the complete chosen lattice. The independent root-subsystem calculation and torus congruence cannot substitute for that check.

\begin{enumerate}
\item \textbf{Narain background:} integral basis, bilinear form, gluing, moduli, Wilson lines, enhanced roots and their identification with geometric components.
\item \textbf{Operator action:} an action preserving the lattice, with a compatible lift, phases and cocycles. Its powers and every required sector must be consistent. Order four in the arithmetic representative must be reconciled with the geometric order-two action.
\item \textbf{Physical matching:} untwisted, twisted and bulk states; matter representations; and the branch deformation dictionary.
\end{enumerate}
These three checks are explicitly \status{UNRESOLVED}, even if an input merely asserts that background data exist.
